Model Deployment · Healthcare AI

ResistomeX

Live AMR resistance-phenotype prediction — my only paper-to-production project

🟢 Live Healthcare

🎯 Problem statement

My AMR resistance-phenotype research — accepted at ECCT 2026 in collaboration with icddr,b — proved the model worked, but a paper sitting in a repository doesn't help anyone. ResistomeX takes the ensemble from that research and deploys it as an interactive, publicly accessible web app.

📊 Dataset

  • Same icddr,b clinical genomic dataset used in the ECCT 2026 paper
  • Covers 12 distinct antibiotic-pathogen combinations

⚙️ Methods & approach

  • R-Blend ensemble: Decision Tree + Logistic Regression + XGBoost, combined via soft voting
  • Resistome Burden Index (RBI) — the novel composite feature introduced in the ECCT 2026 paper
  • Refactored the original research notebook into four clean, self-contained pipeline notebooks (EDA, preprocessing, training, evaluation) suitable for a production-facing app
  • Deployed as a public web app on Streamlit Community Cloud

💡 What I learned

  • How to turn a research notebook into a maintainable, production-facing pipeline
  • The gap between "the model works" and "a stranger can use this without me" — input validation and interpretable output
  • Deploying and maintaining a live ML app on Streamlit Community Cloud

Multimodal Disaster Severity Classifier

Late-fusion vision + text model for bilingual disaster response

Multimodal Bilingual

🎯 Problem statement

Emergency responders need to prioritize disaster reports fast, but reports arrive as a mix of images and bilingual (Bengali/English) text. This project classifies disaster severity from image + text pairs to support triage and response prioritization.

📊 Dataset

Dataset: datathon-iiuc-cse-fest-2026 — TODO: add exact sample size and class distribution once finalized.

04 🧬

Classification · Healthcare AI · Research

AMR Resistome Prediction

SVM-XGBoost ensemble with a novel Resistome Burden Index — accepted at ECCT 2026

Published Classification

🎯 Problem statement

Antimicrobial resistance (AMR) is one of the most urgent global health threats, and standard lab diagnostics can take 24–72 hours. This research — accepted at ECCT 2026 in collaboration with icddr,b — predicts antibiotic resistance phenotypes from genomic and clinical features using ensemble machine learning, enabling faster, data-driven treatment decisions.

📊 Dataset

  • icddr,b (International Centre for Diarrhoeal Disease Research, Bangladesh) clinical genomic dataset
  • Binary classification target: antibiotic-susceptible vs. antibiotic-resistant phenotype

⚙️ Methods & approach

  • SVM-XGBoost ensemble combined with a novel Resistome Burden Index (RBI) composite feature
  • Class imbalance handling via SMOTE oversampling and class-weight adjustment
  • Statistical validation: McNemar's test, Bootstrap CI, and Wilcoxon signed-rank for model comparison

💡 What I learned

  • Designing an interpretable composite feature (RBI) rather than relying on a black-box ensemble alone
  • Handling noisy genomic labels and class imbalance in a real clinical dataset
  • Running rigorous statistical significance testing for model comparison in a peer-reviewed paper

DevSearch

A developer discovery and networking platform — find engineers, explore their projects, and connect.

🎯 Problem solved

Developers building side projects or looking for collaborators have no dedicated space to discover each other by skill set. LinkedIn is too corporate; GitHub profiles lack structured search. DevSearch fills that gap with a clean, skill-indexed directory built specifically for the engineering community.

✨ Key features

  • ✓ Developer profile creation with skills, bio, and project links
  • ✓ Full-text search and filter by technology stack
  • ✓ JWT-based authentication and authorization
  • ✓ Project showcase with tags, descriptions, and GitHub links
  • ✓ Messaging / connection request system between developers
  • ✓ Paginated REST API with Spring Boot backend

AI Lesson Planner

Helping teachers spend less time planning and more time teaching — AI generates structured, editable lesson plans on demand.

🎯 Problem solved

Teachers spend hours every week writing lesson plans from scratch — adapting the same structure for different grade levels, subjects, and learning objectives. This tool removes the blank-page problem: enter topic, grade, and duration, and receive a complete, pedagogically-structured plan within seconds. Teachers then edit, save, and reuse plans from their dashboard.

✨ Key features

  • ✓ Teacher dashboard to save, edit, and organise saved plans
  • ✓ Grade level and subject customisation inputs
  • ✓ PDF export of completed lesson plans
  • ✓ Role-based accounts: teacher and admin roles

Backend
Node.js Express.js OpenAI API REST API
Database & Infra
MongoDB Docker JWT Auth

School Management System

A complete administrative platform for schools — student records, attendance, grades, and staff management in one system.

🎯 Problem solved

Schools managing student enrollment, attendance, and academic records across paper files and spreadsheets lose data integrity and waste administrative time. This system centralises all school operations into a single platform — with separate dashboards for admins, teachers, and students, each seeing only what they need, secured by role-based access control.

✨ Key features

  • ✓ Student enrollment, transfer, and graduation record management
  • ✓ Daily attendance tracking per class with teacher interface
  • ✓ Grade entry, report card generation, and GPA calculation
  • ✓ Staff and teacher profile management with subject assignments
  • ✓ Role-based access control: Admin / Teacher / Student / Parent
  • ✓ REST API backend with full Swagger/OpenAPI documentation
  • ✓ Dockerised deployment with environment variable configuration

⚙️ Tech stack

Backend
Java 17 Spring Boot 3 Spring Security Spring Data JPA
Database & Infra
MySQL 8 Docker Jenkins Swagger / OpenAPI
Auth & Security
JWT BCrypt RBAC

👤 My role

Sole developer. Designed the full relational database schema including entity relationships for students, classes, subjects, and staff. Implemented the complete Spring Boot backend with layered architecture (Controller → Service → Repository). Built role-based security using Spring Security with JWT. Containerized the application with Docker and set up a Jenkins pipeline for automated builds.

How I work

My engineering approach

Every project follows the same structured process — from problem definition to deployment.

📋
01

Define the problem

I start with the user problem, not the technology. What pain point does this solve? Who uses it? What does success look like?

🗄️
02

Design the data model

Schema design before writing a single line of application code. Clean entity relationships prevent technical debt later.

⚙️
03

Build the API first

Backend REST API with full validation, error handling, and documentation before touching the frontend. API-first thinking keeps concerns cleanly separated.

🖥️
04

Build the UI

Frontend consumes the documented API. Component-based structure, state managed cleanly, accessibility considered from the start.

🐳
05

Containerise & deploy

Docker for consistent environments. CI/CD pipelines with GitHub Actions or Jenkins to automate testing and deployment. No "works on my machine" problems.

📝
06

Document & reflect

README, API docs, and a case study write-up. What went well, what I'd change, and what I learned — shared publicly on the blog.

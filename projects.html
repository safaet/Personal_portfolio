Project 01

DevSearch

Developer Discovery Platform

Problem solved

Developers struggle to find collaborators, showcase their work, and connect with peers in a meaningful way. LinkedIn is too broad; GitHub lacks profile depth. DevSearch fills this gap — a focused platform where engineers can be discovered by their actual skills and project history.

Tech stack

React 18 Java 17 Spring Boot Spring Security + JWT PostgreSQL Docker REST API

My role

👨‍💻 Solo Full Stack Developer
Completed ~ 8 weeks

Key features

  • 🔐
    JWT Authentication & Authorization Secure register/login with role-based access. Stateless token auth across all API endpoints.
  • 🔍
    Skill-based Developer Search Full-text search with skill filters. Paginated results ranked by profile completeness and activity.
  • 👤
    Rich Developer Profiles Skills, project showcase, bio, social links, and endorsements — all editable in real time.
  • 📨
    Connection Requests & Messaging Send and accept connection requests. In-app messaging between connected developers.
  • 🐳
    Dockerized Deployment Docker Compose setup for one-command local development and consistent staging environment.

Project 02

AI Lesson Planner

AI-Powered EdTech Tool

Problem solved

Teachers spend 2–4 hours per week writing lesson plans — time that could go toward actual teaching. AI Lesson Planner automates this: a teacher enters a topic, grade level, and duration, and the system generates a complete, structured, editable lesson plan in seconds. This was also my first production integration of an LLM API.

Tech stack

React 18 Node.js Express.js OpenAI API MongoDB REST API JWT Auth

My role

👨‍💻 Solo Full Stack Developer
Completed ~ 5 weeks

Key features

  • 🤖
    AI Lesson Generation Structured prompts to OpenAI's GPT API return complete lesson plans with objectives, activities, and assessments.
  • ✏️
    Editable Plan Output Generated plans are fully editable before saving. Teachers can tweak, reorder, and regenerate individual sections.
  • 💾
    Plan Library & History All saved plans are stored per user in MongoDB. Teachers can revisit, duplicate, and version their plans.
  • 🎛️
    Curriculum Controls Grade level, subject, duration, learning style, and difficulty inputs allow fine-grained plan customization.
  • 📤
    Export to PDF One-click PDF export of any saved plan — formatted and ready to print or share with school administrators.

Project 03

School Management System

Enterprise Web Application

Problem solved

Many schools in Bangladesh still manage enrollment, grades, and attendance using spreadsheets and paper records — making data retrieval slow and error-prone. This system digitizes the entire administrative workflow: from student registration and daily attendance to grade reporting and staff management, with separate dashboards for admins, teachers, and students.

Tech stack

Java 17 Spring Boot Spring Security Spring Data JPA MySQL Docker Jenkins CI REST API

My role

👨‍💻 Solo Backend & Architecture Lead
In Progress Frontend integration ongoing

Key features

  • 🔐
    Role-Based Access Control Three distinct roles: Admin, Teacher, Student. Each role sees only the data and actions relevant to them.
  • 📋
    Student Enrollment & Records Full CRUD for student profiles, class assignments, guardians, and enrollment history with audit logs.
  • 📅
    Attendance Tracking Teachers mark daily attendance per class. Admins get attendance reports by student, class, or date range.
  • 📊
    Grade Management & Reporting Teachers submit grades per subject. System calculates totals, averages, and generates printable report cards.
  • 🔄
    CI/CD with Jenkins & Docker Automated build and deployment pipeline. Docker Compose manages app, database, and reverse proxy services.

Project 01

DevSearch

Developer Portfolio & Skill-Matching Platform

Problem solved

Developers need a way to build a portfolio and get matched to opportunities based on their actual skills, not just a resume. DevSearch is a full-stack platform where developers create a profile, showcase projects, and get discovered by skill.

Tech stack

Django HTML CSS JavaScript AWS

My role

👨‍💻 Full-Stack Developer
Deployed on AWS

Key features

  • 👤
    Developer Profiles Developers create a profile with a skill list and a showcase of their own projects.
  • 🔍
    Skill-Based Matching Developers can be discovered and matched to opportunities by their listed skills.
  • ☁️
    Deployed on AWS Built with Django on the backend and deployed to AWS.
